# 设计令牌速查

全部定义在 `src/index.css`。**组件里不许出现颜色字面量** —— 写死的那一处在另一个主题下必然是错的，而且只有换主题时才看得出来。

## 颜色

| 令牌 | 浅色 | 深色 | 用在哪 |
| --- | --- | --- | --- |
| `--bg` | `#f4f6f8` | `#171b22` | 窗口底色。画在 `html` 上，不画在 `body` 上 |
| `--surface` | `#ffffff` | `#1f242d` | 浮起来的面：提示框、弹窗 |
| `--group` | `rgba(255,255,255,.6)` | `rgba(232,240,248,.075)` | `Group` 的底。深色下低于 0.075 就分不出组了 |
| `--stage` | `#e8f4fd` | `#1e2837` | 强调区域的底（横幅、空状态） |
| `--page-bg` | `#dfe4ea` | `#0c0f13` | 页面容器外的更深一层 |
| `--ink` | `#1e242b` | `#e4e9ef` | 正文 |
| `--ink-muted` | `#5d6874` | `#a9b3be` | 次一级正文 |
| `--help` | `#8a949e` | `#828c96` | 控件旁的说明 |
| `--meta` | `#a3acb6` | `#6e7883` | 最轻的一档：时间戳、分类 |
| `--hairline` | `rgba(30,36,43,.1)` | `rgba(232,240,248,.14)` | 内描边 |

| `--accent-ink` | `#ffffff` | `#0f1319` | 压在强调色上的文字 |
| `--accent-soft` | `rgba(18,137,240,.1)` | `rgba(74,163,240,.14)` | 强调色的淡底 |

关闭按钮悬停的红（`#e81123`）故意不走令牌：那是 Windows 的系统语汇，不属于产品配色。

## 圆角

| 令牌 | 值 | 用在哪 |
| --- | --- | --- |
| `--r` | `14px` | 卡片、分组 |
| `--rs` | `8px` | 按钮、输入框、提示框 |

只有这两档。要第三档先想清楚它和这两档的分工。

## 缓动

| 令牌 | 值 | 用在哪 |
| --- | --- | --- |
| `--ease` | `cubic-bezier(.22,1,.36,1)` | 通用：悬停、按下、颜色 |
| `--ease-nav` | `cubic-bezier(.32,.72,0,1)` | **只用于换页**。起步快收尾长，不冲过终点 |
| `--spring` | `cubic-bezier(.34,1.42,.64,1)` | 小元件。**会冲过终点** |

`--spring` 的控制点 `y=1.42` 会让进度在 62% 处到 1.058。整页平移用它的话，页面层会越过静止位置约 0.35% 宽 —— 1185px 的窗口下就是 4px。页面层是 `absolute inset-0`，那 4px 等于在窗口边开了一条缝，缝里露出正在淡出的上一页：一条带着字的竖线。

所以换页只用 `--ease-nav`。分段控件的滑块和浮层可以继续用 `--spring`，它们不贴窗口边。

## 字号

| px | 字重 | 用在哪 |
| --- | --- | --- |
| 25 | 600 | `PageHead` 大标题（≤860px 时降到 22） |
| 15.5 | 600 | `Block` 小标题 |
| 15 | 400 | 正文（`body`，行高 1.65） |
| 14 | 400 | `ListItem` 标题 |
| 13 | 400 | 控件内文字 |
| 12.5 | 400 | 说明文字（`--help`） |
| 11.5 | 400 | meta（`--meta`） |

数字成列时加 `tabular-nums`，否则拖动数值条时右边那一列会因为 `1` 比 `8` 窄而抖。

**不要用 `ch` 限制中文行宽。** `ch` 是「0」字形的宽度，12.5px 字号下实测 6.95px，只有一个汉字的一半。按拉丁文校准的 `74ch` 折成中文只剩 41 字、约容器宽度的 47% —— 用户看到的是「一行话没走到一半就断了」。

## 动画类

| 类 | 用在哪 |
| --- | --- |
| `.page-enter-l` / `.page-leave-l` | 往右翻页（新页从右推入） |
| `.page-enter-r` / `.page-leave-r` | 往左翻页 |
| `.seg-thumb-move` | 分段控件滑块的挤压 |
| `.btn-dots` | 按钮上的「正在做」回执 |
| `.trm-bar-indeterminate` | 不确定进度条 |
| `.tooltip-in` | 提示框入场 |
| `.nudge-in` | 邀请式提示入场 |
| `.spotlight` | 落点高亮，1.6 秒后自灭 |

换页的两层必须**时长相同**（0.42s）而**位移不同**（新页 6%、旧页 2.5% 且带缩小）。等距离平移是一张纸横着拖过去，差速才有前后关系。时长不同的话，中间那段会出现一层孤零零地滑，动作断成两截。

`PageHost` 里的 `LEAVE_MS` 必须和 `.page-leave-*` 的时长一致。短了是动画放到一半节点被拔掉，长了是看不见的图层继续占着。

## 壁纸

`lib/appearance.ts` 往 `<html>` 上写三个变量，`body::before` 负责画：

- `--wp-image` — `url(…)`，空则不画
- `--wp-blur` — 高斯半径，滑杆 0–100 映射到 0–24px。再糊下去就只剩一团颜色
- `--wp-opacity` — 0–1

底色必须画在 `html` 上。`body::before` 是 `z-index: -1`，负层级只能画在画布背景之上；`body` 自己带不透明底色的话，壁纸被压在下面，画了等于没画 —— 而且磨砂和不透明度会跟着一起「没反应」，因为三个设置改的是同一个看不见的图层。
