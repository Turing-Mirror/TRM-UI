# 分类平移 v1

`Panes` 可设置 `transition="slide"`，按 `order` 决定方向。两个分类使用相同的时长与曲线，水平平移一个容器宽度，不改变透明度或缩放比例。默认 `push` 和其他控件保持原样。

反向选择从当前绘制位置继续。切换中选择第三个分类时，先完成当前两页的平移，再转到最后选择的分类；期间保留可见内容，避免移除半途中的页面而露出空白。`usePaneOn` 在分类已被请求切走时返回 false，供异步内容保留离场快照。

隐藏分类仍保留输入和局部状态。启用减少动态效果时直接切换。分类容器只裁切横向溢出。

验证：共享组件 86 项测试通过，库构建和 lint 通过。新增回归覆盖位移方向、无透明度与缩放动画、保留输入、反向接续、第三项选择和默认动效兼容。
