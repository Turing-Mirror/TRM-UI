# 交互约定

写给使用 TRM UI 的人和 AI。每条先用一句话说明，再给"该做的"和"不该做的"对照。

用户可见文案与翻译遵循 [桌面软件文案原则与廉耻表](copywriting.md)。文案示例涉及的视觉与交互行为，以本约定和当前源码为准。

## 图标按钮没有底

只有图标、没有文字的小按钮（删除、详情、播放、编辑、收起等），任何时候都不画底色。鼠标指上去、按钮处于打开或选中状态时，只改变图标本身的颜色：变深，或换成对应的语义色。

图标按钮通常成排出现，或者贴在一条内容旁边。给它加底，就会在内容旁冒出一个个小色块，看上去像另一种控件，也会抢走内容的注意力。

| 该做的 | 不该做的 |
| --- | --- |
| 平时用弱化色（`--ink-muted`），指到时变成正文色（`--ink`） | 指到时出现浅灰底、圆形底或描边 |
| 打开的状态（例如详情浮层已展开）保持正文色，或用强调色（`--accent`） | 打开的状态用一块浅色底标出来 |
| 删除类按钮平时用较淡的红，指到时变成完整的红（`--danger`） | 删除类按钮带一块浅红底 |
| 颜色变化走过渡，和其他控件的时长、曲线一致 | 颜色瞬间跳变，或者配上缩放、位移等额外动效 |
| 用 `IconBtn` 组件，`label` 必填，读屏和悬停提示都用它 | 自己拼一个带 `hover:bg-*` 的按钮 |
| 同一处的操作只有一个入口，例如清空只放一个按钮 | 同一个操作既有图标按钮又有文字按钮，并排出现 |

带文字的按钮不受这条约束，仍按 `Btn` 的样式有底。

## 浮层贴着打开它的按钮

点一个按钮打开的浮层（详情、菜单、提示），以按钮本身为锚点定位，贴着按钮出现。

| 该做的 | 不该做的 |
| --- | --- |
| 锚点是被点的那个按钮 | 锚点是按钮外面一个占满整行的容器，浮层飘到行的另一端 |
| 空间不够时翻到另一侧，并收在窗口里 | 浮层被窗口边缘截断，或者跑出窗口 |

## 不用分割线、分隔点和破折号拼凑内容

界面文字用正式、完整的陈述句，或者"名称：值"的字段。不要用横线、"·"、"——"把几个词串成一行，也不要用横线把一张卡片切成几段。

用符号串起来的一行，读的人要自己猜每一段是什么、段与段之间是什么关系。它省掉的正是该写清楚的那部分。分区靠底色块和留白，不靠线。

### 分割线

错误示范：卡片里输入框、选项行、按钮行之间各画一条横线。

```tsx
<div className="flex items-center gap-2 pt-2.5 mt-2 border-t border-[var(--hairline)]">…</div>
```

正确示范：同一张卡片里的几行只用间距隔开；确实是另一组内容，就放进另一个 `--group` 底色块。

```tsx
<div className="flex items-center gap-2 mt-3">…</div>
```

### 分隔点

错误示范：

> 厦大 · 生殖泌尿科 · 册主任 · 30项验收通过

> v2ProPlus · 未填写作者

> 15:51 · 1.5 s · alice_test · 种子 1092174532

正确示范：

> 厦门大学生殖泌尿科册主任主持的验收已完成，30 项全部通过。

> 模型版本：v2ProPlus
> 作者：未填写

> 角色：alice_test
> 时长：1.5 秒
> 随机种子：1092174532

### 破折号

错误示范：

> 厦大——生殖泌尿科——册主任——30项验收通过

> 当前是纯网页预览——窗口按钮、托盘一律安静降级。

> 有效时长　—

正确示范：

> 厦门大学生殖泌尿科册主任主持的验收已完成，30 项全部通过。

> 当前是网页预览。窗口按钮和托盘需要桌面程序，在网页中不可用。

> 有效时长：未检测

### 对照

| 该做的 | 不该做的 |
| --- | --- |
| 写成完整的陈述句，主语、谓语齐全 | 用"·"或"——"把几个名词串成一行 |
| 多项信息写成"名称：值"，每项一行，或排成两列 | 只给值不给名称，让读的人猜每一段是什么 |
| 用全称，例如"厦门大学""随机种子" | 用简称或缩写，例如"厦大""种子" |
| 值缺失时写明原因，例如"未检测""未填写" | 用"—"或空白占位 |
| 同一张卡片里的几行只用间距隔开 | 每组控件之间加一条 `border-t` |
| 列表空间不够时少放几项，其余放进详情 | 把所有字段挤进一行再用符号隔开 |

这条只管界面上的文字和布局。代码注释与开发文档不受约束。

## 用用户听得懂的话

界面文字面向使用者，不面向开发者。不用内部术语、行话和口语缩略，数字带上完整的单位和它的含义。没有分隔符的一串词组同样不合格。

错误示范：

> 首包 2828 ms　已出 3 段　已用 3.7 s

正确示范：

> 已生成 3 段语音，用时 3.7 秒，其中第一段用时 2.8 秒。

| 该做的 | 不该做的 |
| --- | --- |
| 写使用者熟悉的说法，例如"第一段语音" | 写开发者的术语，例如"首包""TTFB" |
| 用完整的动词，例如"已生成" | 用缩略的说法，例如"已出" |
| 单位写成文字，例如"秒""毫秒" | 正文里混用 `s`、`ms` |
| 同一处的几个数字口径一致，例如都从点击开始计时 | 进行中显示一种计时，结束后换成另一种 |

## 同一句话只出现一处

一条信息在当前视图里只出现一次。同一屏有两个位置都能放它时，放在离相关操作最近的那一处；另一处只在前者不可见时才显示。

错误示范：训练页第一步的内容区写着"底模仍缺少 2 个文件"，右侧状态栏底部同时写着"底模仍缺少 2 个文件，请先在广场补全资源。"

正确示范：停在第一步时只在内容区说明；切到其他步骤，内容区看不到这句时，再由状态栏提示。

| 该做的 | 不该做的 |
| --- | --- |
| 说明放在离相关操作最近的地方 | 同一个提示在内容区和侧栏各放一份 |
| 一处不可见时，再由另一处补上 | 为了"保险"在多处同时提示 |
