# 交互约定

写给使用 TRM UI 的人和 AI。每条先用一句话说明，再给"该做的"和"不该做的"对照。

界面文字的写法见画廊的「文本要求」页，内容在 `src/pages/textRules.ts`。

## 图标按钮没有底

只有图标、没有文字的小按钮（删除、详情、播放、编辑、收起等），任何时候都不画底色。鼠标指上去、按钮处于打开或选中状态时，只改变图标本身的颜色：变深，或换成对应的语义色。

图标按钮通常成排出现，或者贴在一条内容旁边。给它加底，就会在内容旁冒出一个个小色块，看上去像另一种控件，也会抢走内容的注意力。

| 该做的 | 不该做的 |
| --- | --- |
| 平时用弱化色（`--ink-muted`），指到时变成正文色（`--ink`） | 指到时出现浅灰底、圆形底或描边 |
| 打开的状态（例如详情浮层已展开）保持正文色，或用强调色（`--accent`） | 打开的状态用一块浅色底标出来 |
| 删除类按钮平时用较淡的红，指到时变成完整的红（`--danger`） | 删除类按钮带一块浅红底 |
| 颜色变化走过渡，和其他控件的时长、曲线一致 | 颜色瞬间跳变，或者配上缩放、位移等额外动效 |
| 用 `IconBtn` 组件，`label` 必填，读屏和悬停提示都用它 | 自己拼一个带 `hover:bg-*` 的按钮 |
| 同一处的操作只有一个入口，例如清空只放一个按钮 | 同一个操作既有图标按钮又有文字按钮，并排出现 |

带文字的按钮不受这条约束，仍按 `Btn` 的样式有底。

## 浮层贴着打开它的按钮

点一个按钮打开的浮层（详情、菜单、提示），以按钮本身为锚点定位，贴着按钮出现。

| 该做的 | 不该做的 |
| --- | --- |
| 锚点是被点的那个按钮 | 锚点是按钮外面一个占满整行的容器，浮层飘到行的另一端 |
| 空间不够时翻到另一侧，并收在窗口里 | 浮层被窗口边缘截断，或者跑出窗口 |
