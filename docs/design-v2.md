# 设计规范 v2（草稿）

状态：部分执行。已执行的在各节末尾注明，其余等待确认。

来源：设计评审 v1 和 2026-11-11 的讨论结论。

## 1. 三层结构

1. **底层只有一套。** 颜色、字号、间距、圆角、动效时长，所有外观共用。
2. **行为只有一套。** 键盘操作、焦点、无障碍、状态逻辑，每个组件只写一次。
3. **外观可以有多套。** 每套有名字，并写明适用场合。

外观并存的两个条件：

- 按产品选，不按单个位置选。产品在入口处声明，产品内部保持一致。
- 有真实需求才算一套。只是历史写法不同的，合并。

第一批外观轴：

| 轴 | 可选值 | 适用 |
| --- | --- | --- |
| 外壳 | 顶部滑块、侧栏 | 页面不超过 7 个且名称短用顶部滑块；页面多、有分组或有常驻任务用侧栏 |
| 密度 | 标准、紧凑 | 工具面板和数据密集的页面用紧凑 |
| 卡片 | 平铺、浮起 | 设了背景图时用浮起 |

## 2. 字号

七档，构建检查强制。

| 档 | 字号 | 用途 |
| --- | --- | --- |
| 页标题 | 25 | 每页一个 |
| 区块标题 | 16 | 分组标题 |
| 正文 | 15 | 段落 |
| 控件 | 13 | 按钮、输入框、页签、列表行 |
| 说明 | 12.5 | 帮助文字 |
| 附注 | 11.5 | 时间、计数、单位 |
| 数值 | 22 | 统计数字 |

现有的 10、11、12、13.5、14、15.5、17、18 并入最近的一档。

中文字重只用两档：常规和粗体。随程序带可变字重字体之后再启用中等字重。

## 3. 颜色

灰字从四级改成三级，浅色模式下全部达到 4.5 比 1。

| 变量 | 现在 | 建议 | 白底对比度 |
| --- | --- | --- | --- |
| `--ink` | #1e242b | 不变 | 合格 |
| `--ink-muted` | #5d6874 | 不变 | 5.7 |
| `--help` | #8a949e | #66717c | 5.0 |
| `--meta` | #a3acb6 | 并入 `--help`，靠字号区分 | 5.0 |

状态色分成"底色"和"文字"两个值。底色保持现在的亮度，文字用加深的一档。

| 用途 | 底色 | 文字 | 文字白底对比度 |
| --- | --- | --- | --- |
| 强调 | #1289f0 | #0b6fc7 | 5.1 |
| 成功 | #2f9e6a | #1f7d51 | 5.1 |
| 警告 | 现有 | #9a6200 | 5.1 |
| 危险 | #d0533f | #b8432f | 5.4 |

已执行（2026-11-12）：`--help` 改为 #66717c，`--meta` 与它同色；新增 `--accent-text`、`--ok-text`、`--danger-text`，文字改用这三个变量，图标和底色不变；`--warn-ink` 改为 #9a6200。深色模式下 `--meta` 抬到与 `--help` 相同。

主按钮白字压在 #1289f0 上是 3.6 比 1。两个选择：按钮底色改为 #0b6fc7，或保持底色并接受这一处不达标。这一项要你定。

状态不只靠颜色表达：状态标签带图标或文字，同色圆点改成不同形状或加文字。

## 4. 间距

以 4 为单位：4、8、12、16、24、32、48。现有的 7、9、11、13 并入最近的值。

卡片内边距大于卡片之间的间距。表单控件按内容定宽，不铺满整行。

## 5. 圆角和层级

圆角保持两档：14 和 8。

层叠数值收成命名的五层：内容 0、吸顶 10、浮层 100、弹窗 200、通知 300。

## 6. 动效

时长四档，曲线三条。

| 档 | 时长 | 用途 |
| --- | --- | --- |
| 即时 | 100 | 按下、离场、悬停 |
| 快 | 200 | 菜单、提示、淡入 |
| 中 | 300 | 弹窗、抽屉、通知 |
| 慢 | 420 | 整页推移、伸缩、列表重排这类大位移 |

| 曲线 | 用途 |
| --- | --- |
| `--ease` | 入场和所有由用户触发的反馈 |
| `--ease-nav` | 大位移 |
| `--ease-out-quick` | 离场 |

规则：

- 点击当帧给结果，动画不让内容等待。
- 两份内容不同时可见，除非它们相邻推移且全程不透明。
- 只动 transform 和 opacity。确实要改尺寸的，限制在不带动其他内容的小范围内。
- 可能被连续触发的动效要能从当前位置接着走。
- 键盘触发的切换不放动画。

已执行的部分：分段滑块点击当帧切换；换页为整页推移，新旧两页首尾相接、全程不透明、可中途接续（2026-11-11）。

## 7. 按钮

- 主按钮：每个区域最多一个。卡片列表里每张卡片可以有一个。
- 新增文字按钮，用于次要和重复出现的操作。
- 新增危险样式，用于删除和卸载。
- 禁用状态和默认状态要一眼分得开。
- 按下缩到 0.97。

## 8. 文案

值本身看不出含义时才加名称。例如"12 MB"不需要"大小："，"未填写"需要"作者："。

## 9. 保留的特意设计

- 问号提示的数量保留，只统一位置：放在名称之后。
- 滚动条全局隐藏保留。确实要滚动的区域在底部加渐隐。对外提供一个开关。
- RVC 底部控制条常驻。

## 10. 构建检查

变量以外的字号、圆角、时长、层叠数值和手写输入框报错。

已执行（2026-11-12）：`trm-design-check` 接入三个项目的构建。现有的写法记入基线，只拦新增。字号的允许范围暂时包含现行的 14 和 15.5，等第 2 节确认后收紧。

自定义的合法方式：覆盖变量、选择外观。个别例外在该行加一句说明后放行。
